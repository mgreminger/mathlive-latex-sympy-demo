MathLive -> LaTeX -> SymPy Demo

Status: Initializing Pyodide and downloading SymPy (this takes a moment)...

1. MathLive Input

\frac{x^2 - 1}{x - 1} + \sin^2(x) + \cos^2(x)

2. Extract Raw LaTeX (JavaScript)

const raw_latex = mfInput.value;
...

3. Parse Expression (Python)

# requires antlr4-python3-runtime
expr = sympy.parsing.latex.parse_latex(raw_latex)
...

4. Simplify Expression (Python)

simplified_expr = sympy.simplify(expr.doit())
...

5. Convert to Output LaTeX (Python)

final_latex = sympy.latex(simplified_expr)
...

6. MathLive Rendered Output (JavaScript)

mfOutput.value = final_latex;
